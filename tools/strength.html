Difficulty comparison

Measures how each AI level would feel to people of different strength. Every level plays simulated players from both seats, and the page checks how predictable each level is: whether it repeats itself, and whether it falls for known trap lines. The levels come from the LEVELS table in js/engine.js, so after editing that table just run this again. To try settings without touching the engine, add them under Extra configs. Settings are kept in the page address, so a run can be repeated or shared.
